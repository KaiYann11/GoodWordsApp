최신 버전 다운로드

이렇게 설치하세요

1.4.1에서는 보관함 탭이 글귀 · 아이디어 · 독서 · 개념 · 메모 · 임시저장소 차례가 되고, 메모·개념 탭에서 + 직접 쓰기로 바로 담을 수 있습니다. 개념에서는 AI에게 의미 묻기로 짧은 설명을 받아 함께 둡니다. 1.4.0부터 설정 → AI 돌아보기에서 Claude CLI·Codex CLI를 고르면 API 키 없이 PC 서버에 로그인해 둔 CLI가 답합니다. 여러 기기를 연결해 쓴다면 모두 최신 버전으로 업데이트해 주세요.

  1. 최신 버전 다운로드를 누릅니다.
  2. 다운로드가 끝나면 알림이나 브라우저의 다운로드 목록에서 APK 파일을 엽니다.
  3. 처음 설치할 때 출처 허용 안내가 나오면, 파일을 내려받은 브라우저의 설치를 허용합니다.
  4. Android 설치 화면에서 업데이트 또는 설치를 누릅니다.

기존 앱을 삭제하지 않고 업데이트해 주세요. 설치 전 앱 설정에서 데이터를 내보내 두면 기록을 별도로 보관할 수 있습니다.

1.1.1부터 앱의 서버 주소는 HTTPS만 사용할 수 있습니다. 휴대폰과 PC의 Tailscale 연결을 켜고, 앱 설정에도 이 사이트의 HTTPS 주소를 입력해 주세요. 기존 접속 키는 그대로 사용합니다.

서버 홈으로 · 같은 Tailscale에 연결되고 PC가 켜져 있을 때 이용할 수 있습니다.
